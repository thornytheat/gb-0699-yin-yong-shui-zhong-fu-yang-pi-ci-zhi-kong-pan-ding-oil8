# 饮用水批次质控定义

id保留前导零；batch+analyte+pair决定平行样配对。kind为sample、duplicate、spike、blank。浓度单位mg/L、ug/L统一为mg/L；数值用Decimal。检出限Pb、As均为0.001mg/L，限定值形式<0.001不按零处理。

均值低于5倍检出限时，平行样采用绝对差<=检出限；其余采用差值/均值<=20%。双零通过绝对差规则。加标回收=(加标样-本底)/加标量×100%，80—120%通过；加标量非正失败。空白严格超过检出限才判污染。

同id最高version为生效复测，同版本重复隔离。放行优先级为空白污染、空白缺失、回收失败、加标异常、配对失败、限定值复核。每个批次每项必须有空白；受限值进入人工复核。失败检测批生成逐样复测任务和下一最低版本。

复测采用batch+analyte+id作为身份键，在此身份内选择最高version；不同检测项允许复用同样品编号。版本按数值比较，`01`与`1`同版。

## 增量复测与结论版本

- 复测只提交新增版本，不重传原批次；按身份键逐行裁决：
  - 高于当前最高版：生效（APPLIED）；
  - 同版同值（含版本写法差异）：重放（REPLAY），不新增结论版本；
  - 同版异值：隔离（VERSION_CONFLICT）；
  - 低于当前最高版：晚到旧版，隔离（STALE_VERSION），有效值不倒退；
  - 版本非正整数：隔离（VERSION），不阻断其余行。
- 生效行使对应 batch+analyte 的放行结论与相关质控项重判：平行样、加标按 pair，空白按自身样品编号。
- 重算与版本校验全部通过后才切换当前结论；切换失败保留旧版结论，操作回到受理阶段，重试同一复测不新增版本。
- 处理进度分阶段持久化（受理 → 已计算 → 已切换），中断后重试从最后确认阶段继续。
- 原批次受理时的原始行、平行样、空白、放行与隔离证据持续可查（结论版本 0），新结论同时保存原证据与上一版结论。
- 复核决定另立台账：切换结论后当前状态回到待复核，但旧决定仍按结论版本可查。
- 对账口径：输入行数 = 当前受理行 + 受理层隔离 + 空行；同版同值重放不重复计数。
